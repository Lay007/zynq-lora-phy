## M4 — Символьный приёмник ZynqSDR

- [x] Подключить сгенерированное ядро к форматированному RX1-потоку AD9361 в
  Vivado. Исходная композиция, gpreg map, CDC-regression, полный board
  implementation, cold boot с SD и smoke test живого RX DMA готовы.
- [x] Подтвердить первый эфирный acquisition от Heltec WiFi LoRa 32 V4.3 на
  868,1 МГц, BW 125 кГц, SF7, CR 4/5. RX1 записал пакет с ожидаемой ориентацией
  IQ, а при ручном усилении 50 dB в PL установился sticky packet-start. Sequence
  metadata осталась нулевой, поэтому восстановление символов/ToA этим не закрыто.
  Протокол: `docs/clg400-hardware-session-2026-09-02.md`.
- [x] Локализовать и замкнуть однопакетный hardware timestamp path. Регрессия
  с живой записью IQ воспроизвела `read_miss` истории 16k; образ с историей 65k
  протрассирован с WNS +0,211 нс и успешно холодно загрузился. Один пакет Heltec
  выдал sequence 1, coarse/fractional ToA, все stage-биты и ни одного sticky
  error. Это доказательство связности, а не приёмочный прогон 1000 пакетов.
- [x] Добавить замороженную PL-трассу из 128 символьных решений и программный
  hard decoder. Timestamp ABI страницы 0 не изменён; RTL-регрессия проверяет
  BRAM и gpreg-страницу, Python golden-векторы — explicit header, FEC,
  whitening и payload CRC.
- [x] Декодировать реальный эфирный payload Heltec при BW 125 кГц и SF7. Одна
  замороженная трасса дала валидный explicit header с валидной checksum,
  валидный LoRa payload CRC и сигнатуру `ZLP1` с тем же sequence number,
  который передатчик сообщил для этой единственной команды `send`. Из десяти
  сохранённых попыток header восстановился во всех, payload — в одной: сетка
  символов не выравнивается по пакету, поэтому дробный остаток портит отдельные
  символы payload. См. `docs/clg400-payload-session-2026-09-03.md`.
- [x] Подать resync коррелятора от детектора, чтобы сетка выравнивалась по
  пакету. Подтверждено на плате: все шестнадцать сохранённых захватов сообщают о
  перевыравнивании и декодируются с нулевой поправкой бина там, где прошлый
  образ требовал четверть символа. Доля принятых payload за этим не последовала:
  3 из 16 против 1 из 10.
- [x] Разрешить развилку между сырым IQ и решениями PL для одностороннего
  сдвига на +1 бин. Он зависит от
  сообщённого бина: 56% по обе стороны от стыка шкалы и 10–18% в середине, и
  разбросан по пакету. Шум до −10 дБ, постоянный суб-чиповый остаток на чистых
  окнах, разрядности Q10/16 бит и CFO до 8 бинов прогнаны через модель по
  отдельности — ни один не воспроизводит картину; догадка по чётности померена
  на тех же захватах и
  отвергнута на 4 из 13. Три одновременных захвата RX DMA и PL декодируются из
  сырого IQ с валидным CRC, а точный двух-FFT эталон совпал с PL в 67 из 72
  решений. Оставшиеся пакет-зависимые поправки +2/+3, −1/−2 и +1/+2 отсчёта
  локализуют дефект в фазе отсчётов, которую не устраняет resync по целым чипам.
- [x] Доказать динамический оцениватель фазы отсчётов в эталонной модели.
  Полусумма полноотсчётных пиков up/down matched filter устраняет CFO; для трёх
  захватов она выбрала +11, −2 и +2 отсчёта, и каждый результат декодировался с
  валидным CRC и нулевой поправкой бина. Синтетический sweep timing/CFO проверяет
  разделение независимо от payload.
- [x] Встроить совместную up/down-оценку в пакетный тракт истории и применить
  поправку к символьной сетке. Повторно используемые поиски ±16 отсчётов вместе
  с наибольшим наблюдавшимся fine skip занимают 137 144 из 145 152 консервативных
  тактов до конца SFD, оставляя 128,128 мкс при 62,5 МГц. RTL-регрессии
  контроллера, history/MAC, resync, portable top и board bridge проходят.
- [x] Локализовано одностороннее смещение `+1 bin` до одной стадии
  воспроизводимым послойным differential (`tools/export_stage_differential.py`).
  На всех трёх одновременных записях IQ/PL все стадии по `peak_bin`
  включительно совпадают, первое расхождение - `symbol`; `correlator_power`
  равен 59/59, то есть обе стороны всегда вычисляли один спектр. Это исключает
  по данным off-by-one, wrap `0 ↔ 127`, знак cyclic shift, конвенцию `+1` bin,
  индексацию MATLAB против RTL, полярность и сопряжение I/Q, signed/unsigned и
  rounding: каждый из них сдвинул бы сам сообщаемый бин. Сырые решения каждого
  пакета попадают ровно в два соседних бина, поэтому единственная целочисленная
  поправка верна для одной группы и ошибочна на один бин для другой:
  односторонность есть свойство расщепления, а не арифметики. 48 из 48
  оставшихся ошибок равны `+1`. Применение совместной поправки up/down к тем же
  окнам даёт 53/53 и корректное декодирование пакета на всех трёх записях.
  Evidence: [`data/clg400-stage-differential-2026-09-08.json`](../data/clg400-stage-differential-2026-09-08.json),
  методика в [stage-differential.md](stage-differential.md). Это evidence
  уровня модели и записи, а не измерение PER.
- [x] Синтезировать portable joint-grid receiver OOC для `xc7z020clg400-2`.
  Vivado 2021.1 сообщает 19 255 LUT, 17 636 регистров, 72 BRAM tile и 56 DSP;
  probe 10 нс имеет WNS −4,032 нс, то есть расчётные 71,266 МГц выше требуемых
  62,5 МГц. Это ещё не timing closure полного board top.
- [x] Развести полный board design с новой сеткой, собрать SD-образ, выполнить
  холодную загрузку и повторить совместный IQ/PL-захват. Выполнено, и гипотеза
  **опровергнута для этой сборки**: post-route закрывается на +0,062 нс WNS и
  +0,011 нс WHS, разведённый netlist содержит joint-grid ячейки, плата
  работает на этом образе, но `raw_decision_bin_spread` остался равен 2 на
  десяти записях из одиннадцати вместо схлопывания до 1. Грубый resync
  удерживает 16-отсчётный guard на 11 записях из 11 против 0 из 12 на baseline,
  а точный запрос, обязанный его вернуть, не приходит, поэтому выданная сетка
  короче на шестнадцать отсчётов. См.
  [`data/clg400-joint-grid-result-2026-09-08.json`](../data/clg400-joint-grid-result-2026-09-08.json).
- [x] Сделан безусловным возврат guard. Удержание грубого guard было
  безусловным, а возврат зависел от успеха совместной оценки, поэтому
  любой аборт поиска оставлял сетку на шестнадцать отсчётов короче, а
  сборку - строго хуже предыдущей. Отказ воспроизведён офлайн на
  ненулевой фазе прихода пакета, исправлен на всех трёх путях и покрыт
  `tb_lora_joint_grid_completion`, который требует возврата guard
  независимо от исхода оценки. Выход `search_abort_error` делает аборт
  видимым.
- [x] Различить молчаливые исходы совместного поиска (липкие биты отказа
  верхнего/нижнего поиска, отказа по диапазону и «точная поправка применена»)
  и найти дефект положения сетки по ground truth. Затем добавлена
  субсэмпловая интерполяция; при усилении 25 дБ декодируется каждый захват
  с нулевой ошибкой сетки. См. [журнал эксперимента](../clg400-joint-grid-experiment.md), шаги M4-M5.
- [x] Одна абсолютная шкала отсчётов на всю серию захватов: `trace_rearm`
  перевооружает трейс и сетку без обнуления счётчика; подтверждено на плате
  на 803,7 с (журнал, шаг M6).
- [x] Закрыть слепую полосу детектора на границе преамбулы и sync (около 7%
  фаз прихода) путём, допускающим straddle, с защитой от тишины. На плате:
